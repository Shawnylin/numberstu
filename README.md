# 百化分 · 速算训练

针对资料分析的百分数 / 常用分数双向练习。原生 HTML、CSS 和 JavaScript，无运行时依赖、无需构建或服务器账号，可直接部署到 GitHub Pages 等静态托管平台。

## 使用

```sh
npm start
```

打开 `http://127.0.0.1:4173/`。也可以用任意静态服务器托管项目根目录。线上使用 HTTPS，才能启用 Service Worker 和安装能力；直接双击 HTML 文件无法加载模块和离线缓存。安装后无需联网即可训练，首次使用需联网准备离线资源。

- **智能练习**：加权随机选题，优先薄弱项和到期复习，定期加入未练过的题。最近八题的首答表现和用时用于调整难度倾向。
- **随机覆盖**：每轮尽量不重复题目，适合检查全部对应关系。单向 30 题一轮可覆盖原有 30 组。
- **错题巩固**：只考待巩固方向，两个方向分别记录；没有错题时给出空状态。
- 可选双向混合或单向练习，每轮 10 / 20 / 30 题，目标用时 5 / 8 / 15 秒。目标用时影响调度，不会强制超时交卷。
- 支持屏幕数字键盘和实体键盘：数字、小数点、Backspace、Delete、Enter。可随时暂停，刷新后从首页继续本轮。
- 查看提示、速记表、答案，或重试、跳过的题，会进入巩固计划。总结列出薄弱项与偏慢题。
- 学习记录包含每日目标、连续练习天数、近 30 轮历史；可导出 / 恢复 JSON 备份。恢复前需点击确认替换。

## 出题与计分规则

题库保留原有 30 组近似对应关系，按答题方向拆成 60 个训练单元。整数分母中的常见转换偏基础，其余整数分母偏进阶，非整数分母偏近似转换；这是启发式分类，并非经过标定的考试难度。

智能调度同时考虑是否首次练习、历史首答正确率、近期用时、记忆等级、复习到期程度和本轮出现次数。题目充足时避开最近三组对应关系，包括反向题，防止刚看到的答案直接成为下一题线索。混合模式尽量使两个方向的出题数量差不超过两题。错题池较小时缩短间隔，只有一组时允许重复。

答错后可自行重试或查看答案，每道题最终只记录一次。**首答正确率**只计未使用帮助、首次独立答对的题，不因重试成功或连续点击虚增；提示和重试不算独立首答正确。离开页面、暂停和打开弹窗时暂停计时。未完成题的输入、首答失败情况和用时会保存。

独立首答正确并达到目标用时后，复习间隔依次为 1、3、7、14、30、60 天。每个方向一天最多晋级一次，达到第三级才显示“已掌握”，防止同一天反复练习虚增掌握度。答错或借助帮助会退回待巩固，约十分钟后到期；累计隔开三道题后也可提前回访。独立答对但偏慢的题会保留正确记录并安排较近复习。达到第二级的历史错题退出错题池，仍参与常规复习。

判题接受速记表答案和等值数值（如 `19` / `19.0`）。其他答案以数学计算值 `100 ÷ 百分数` 或 `100 ÷ 分母` 为中心，允许 **±1% 相对误差（含边界）**，整数和小数使用同一规则，末尾补零不影响判定。例如 `1/1.5 → 66.6667%` 接受 `66`、`66.7`、`67`；`1/16 → 6.25%` 接受 `6.2`、`6.3`，但不接受 `6`、`7`；`27% → 1/4` 仍判错。速记表使用近似号。

## PWA 与数据

- 缓存完整应用资源，包括脚本、样式、manifest 和 192 / 512 像素安装图标；支持部署在仓库子目录。
- 每个版本整体缓存，保证 HTML 与脚本属于同一版本。后续更新通过页面按钮切换，并保存当前训练。
- 老版 `baihuafen-v1` 没有更新按钮，首次迁移会自动启用新版缓存；重新打开或刷新后进入新版。
- 缓存清理按应用路径限定，不删除其他应用缓存；只处理同源应用资源的 GET 请求。
- 所有训练数据保存在当前浏览器的 `localStorage`（键 `baihuafen-state-v2`），不上传云端。多个页面发生数据变动时会同步最新进度并返回首页，避免继续使用已过时的记录。
- 浏览器拒绝存储时仍可训练，并提示及时备份。异常旧数据另存为 `baihuafen-state-v2-invalid-时间戳`，可通过浏览器开发工具取回。
- 数据不会自动跨设备同步，清理网站数据会删除本机记录，请提前导出备份。仅保留最近 90 天的每日统计，但各方向累计统计保留。

## 开发与验证

```sh
npm run check
npm test
```

使用 Node.js 20 或以上的内置测试工具，无需安装依赖。测试覆盖判题、随机覆盖、双向平衡、间隔去重、到期复习、错题回访、掌握度、重复提交、恢复校验，以及 Service Worker 缓存、升级和安装图标。

- `training.js`：纯训练规则与数据校验，便于独立测试。
- `app.js`：交互、计时、存储、备份与安装 / 更新入口。
- `sw.js`：版本化离线缓存。**修改任何运行资源后，务必更新 `VERSION`**，否则已安装用户会继续使用旧版资源。
- `scripts/server.mjs`：仅用于本机开发的静态服务器。
